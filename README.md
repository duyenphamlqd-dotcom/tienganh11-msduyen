## 🚀 Cách triển khai nhanh lên Render (24/24 Miễn Phí)
1. Đẩy thư mục này lên GitHub (xem chi tiết tại `RENDER_HUONG_DAN.md`).
2. Đăng nhập [render.com](https://render.com) bằng GitHub.
3. Chọn **New +** ➜ **Static Site** ➜ Chọn repository.
4. Bấm **Create Static Site** ➜ Website hoạt động 24/7 ngay lập tức!
